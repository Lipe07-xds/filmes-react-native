# 🎬 App de Filmes - React Native

Aplicativo desenvolvido em React Native com Expo que consome a API pública OMDb para pesquisar e exibir informações de filmes.

---

# 📱 Preview

O aplicativo permite:

- Pesquisar filmes pelo nome
- Exibir pôster dos filmes
- Mostrar título e ano de lançamento
- Consumir dados de uma API REST

---

# 🚀 Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- OMDb API
- FlatList
- Fetch API

---

# 🔥 Funcionalidades

✅ Pesquisa de filmes  
✅ Consumo de API REST  
✅ Exibição de pôster  
✅ Interface responsiva  
✅ Lista dinâmica com FlatList  
✅ Busca personalizada

# ▶️ Como executar o projeto

## 1. Clonar o repositório

```bash
git clone https://github.com/Lipe07-xds/filmes-react-native.git
```

---

## 2. Entrar na pasta

```bash
cd filmes-react-native
```

---

## 3. Instalar dependências

```bash
npm install
```

---

## 4. Executar projeto

```bash
npx expo start
```
